# Stop Slop

Remove predictable AI writing patterns from prose.

## Eight Fundamental Rules

1. Eliminate filler phrases
2. Break formulaic structures
3. Use active voice
4. Be specific
5. Engage readers directly
6. Vary sentence rhythm
7. Trust reader intelligence
8. Avoid quotable-sounding lines

---

## Key Problem Areas to Eliminate

### Throat-clearing openers
Phrases like "Here's the thing:" that delay the main point. Cut them. Start with the point.

### Business jargon
- "navigate challenges" → say what the challenge is and what to do about it
- "deep dive" → examine, investigate, study
- "leverage" → use
- "synergy" → cut entirely
- "streamline" → be specific about what gets faster or simpler

### Adverbs and softeners that add no meaning
- "really," "very," "quite," "basically," "essentially," "truly"
- "it's worth noting that," "importantly," "interestingly"
- Cut them all.

### False agency
- ❌ "decisions emerge" → ✅ "we decided"
- ❌ "questions arise" → ✅ "you'll wonder"
- ❌ "challenges exist" → ✅ "this is hard because"

### Binary contrasts that create artificial drama
- ❌ "Not X. It's Y." → say Y directly

### Passive voice that hides actors
- ❌ "mistakes were made" → ✅ "I made a mistake"
- ❌ "it has been found that" → ✅ "researchers found"

### Hedging language
- "it could be argued," "one might say," "in some ways"
- Either say the thing or don't.

### Rhetorical setup
- ❌ "So what does this mean for you?" → just tell them
- ❌ "Now, let's talk about..." → just talk about it

## Practical Scoring (rate before delivery)

Score prose on five dimensions, target above 35/50:

| Dimension | What to check | Score /10 |
|---|---|---|
| Directness | Does it get to the point immediately? | |
| Rhythm | Do sentences vary in length and structure? | |
| Trust | Does it treat the reader as intelligent? | |
| Authenticity | Does it sound like a person, not a template? | |
| Density | Is every word earning its place? | |

## Quick Audit Checklist

- [ ] Remove adverbs (really, very, quite, basically, essentially)
- [ ] Find passive voice and activate it
- [ ] Eliminate em dashes (covered separately in voice-dna)
- [ ] Replace vague declaratives with specifics
- [ ] Ensure sentence length varies (short punches, longer explanations)
- [ ] Cut every "Here's the thing:" / "It's worth noting:" / "Now, let's..."
- [ ] Check that the first sentence makes a real claim, not setup

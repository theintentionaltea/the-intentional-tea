# Frontend Design

Build web components, pages, and applications with exceptional attention to aesthetic details and creative choices. Avoid common AI-generated design clichés.

---

## Before Writing a Single Line of Code

Establish a clear conceptual direction:
- What is the visual language of this page? (editorial, minimal, warm, structured, soft, etc.)
- What is the dominant typographic move? (large serif headline, compressed sans, expressive display)
- What is the color commit? (primary surface, accent, text hierarchy)
- What is the spatial grammar? (generous padding vs. dense, full-bleed vs. contained)

**Bold maximalism and refined minimalism both work. The key is intentionality, not intensity.**

---

## Critical Design Elements

### Typography First
- Prioritize distinctive, characterful fonts
- Pair deliberately — serif + sans is intentional; two similar sans-serifs reads as a mistake
- Never default to Arial, Inter, or any system font without a reason
- For The Intentional Tea: Bodoni Moda (display) + Instrument Sans (body) — already decided, don't override

### Color and Theme
- Commit to a cohesive palette before coding
- Use CSS variables for all color values
- One dominant color, one accent used sparingly
- For The Intentional Tea: Cream (#FAF7F2), Blush (#E2C0B9), Black (#000000)

### Motion
- Animations for high-impact moments only
- Not scattered micro-interactions on every element
- Respect `prefers-reduced-motion`

### Spatial Composition
- Intentional negative space is an active design element, not leftover space
- Asymmetry and intentional imbalance can create tension and interest
- Grid-breaking moments should be deliberate, not accidental

### Visual Details
- Gradients, textures, and patterns should add atmosphere, not decoration
- Every custom effect should serve the page's emotional purpose

---

## Anti-Patterns to Reject

These are signs of generic AI-generated design:
- Purple gradients
- Overused fonts (Plus Jakarta Sans, Poppins, DM Sans as the only choice)
- Predictable card-based layouts for everything
- "Glassmorphism" applied to everything
- Heroicons + Tailwind default spacing = no personality
- Three-column feature grids with icons
- Floating blob decorations

---

## For The Intentional Tea Specifically

The aesthetic target: **Soft luxury meets personal development.** Warm neutrals, clean lines, elevated but not cold. "A well-designed journal you'd actually use." 2026, not 2013.

Every design decision should ask: does this feel like something you'd find in a beautiful bookstore, or something you'd find in a generic digital products template?

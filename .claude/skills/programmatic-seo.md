# Programmatic SEO

Build SEO-optimized pages at scale using templates and structured data.

## Core Principle

**Every page must provide value specific to that page** — not simple variable substitution. Generic pages with swapped keywords get penalized.

Defensible data ranks:
1. Proprietary (yours alone)
2. Product-derived (from your own product data)
3. User-generated
4. Licensed
5. Public (most competitive)

## Implementation Process

### Step 1: Identify Pattern
- Find a repeating keyword pattern (X for Y, X vs Y, best X for Y)
- Validate search demand — is there actual monthly volume?

### Step 2: Source Data
- What unique data do you have that differentiates each page?
- For The Intentional Tea: personal experience, specific product features, niche use cases

### Step 3: Design Templates
- Each page must deliver genuinely unique value
- Template = structure + unique content, not template = structure + swapped variable
- Include: unique headline, unique intro, unique content body, relevant internal links

### Step 4: Internal Linking Architecture
- Hub page links to spoke pages
- Spoke pages link back to hub
- Related spokes link to each other
- Every page is reachable within 3 clicks from the homepage

---

## Quality Assurance

### Pre-launch
- Content uniqueness (each page has something no other page has)
- Technical SEO on every page (title, meta, H1, canonical)
- Internal linking structure in place
- Indexation readiness (no accidental noindex)

### Post-launch monitoring
- Rankings for target keywords
- Organic traffic per page
- Engagement metrics (time on page, bounce rate)
- Watch for thin content warnings or ranking drops
